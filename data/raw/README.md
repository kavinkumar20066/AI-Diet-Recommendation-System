# Raw Data Directory

Place the raw `nutrition_dataset_v1.csv` dataset file here.

Due to unknown licensing restrictions, the raw dataset is not committed to the Git repository.

## Dataset Details
- The file must be named exactly `nutrition_dataset_v1.csv`.
- Expected columns include: `Fat`, `Carbohydrates`, `Sugars`, `Protein`, `Dietary Fiber`, and `Caloric Value`.
